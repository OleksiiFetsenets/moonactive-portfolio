Coinfall — a Coin Master loop,
rebuilt from first principles.

Solo vertical slice · macOS + Android builds · Doom-flavoured

Spin for coins, raid rival bases, upgrade the village, unlock the next island. A full core loop with the economy, persistence, UI and device builds around it.

  • Slot core: 3×3 reels, five paylines, weighted symbols and a triple-BFG jackpot.
  • Meta loop: energy regen and refills, four upgradable buildings with payout multipliers, shield-based raids on bot rivals.
  • Architecture: pure C# core with noEngineReferences, Unity views and adapters, an IStore port for save/load.
  • Proof, not vibes: 13 EditMode tests, a 200,000-spin RTP simulation (~0.99), and an automated UI walkthrough that drives the real buttons.
  • Layout audit: 11/11 behavioural checks and 0 overlap/off-screen problems at 1280×720, 1024×768, 900×500 and 500×900.

HOLYWAR — a duel where
the enemy learns you.

First-person medieval duel · hand-drawn sprite animation

A knight duel on Android, drawn and animated frame by frame, with a small neural network behind the knight’s shield. No game engine. No animation library. No ML library.

  • Sprite pipeline: a custom Python packer trims, deduplicates and atlases every frame; the sheets take 43% less space and animations live in JSON.
  • Combat feel: layered sprites, hits land on exact animation frames, and a guard-stamina loop creates the openings you have to read.
  • Learning enemy: an 18 → 16 → 4 MLP written from scratch — matrix math, forward pass and backprop — that updates from how you react after each decision.
  • Real training: the diagram is drawn from saved weights after 211 samples across 30 battles; the strongest inputs are the knight’s own guard attempts.

Kusaku — a Sudoku app
with a personality.

Android · five difficulties · four themes · APK built

A complete Sudoku product: pencil marks, undo, hints, timer and autosave — plus a cyberpunk theme that is a live Canvas, not a skin.

  • Product depth: five difficulty levels, same-digit highlighting, per-cell 3×3 pencil marks, undo, hints, timer and autosave.
  • Noob mode: refuses a wrong digit instead of punishing it, so the board can never enter a wrong state.
  • Cyberpunk theme: animated parallax grid, drifting data streams, RGB-split title and tearing bursts — rendered from a single animated float and frozen when system animations are off.
  • Beyond Android: iOS port in progress; unit tests cover the engine, generator and save format.

WalkingFarmer —
a small world that reacts.

800×608 SFML window · 32px tile map · day/night cycle

A tile-based farming sandbox: walk around, dig or plant grass, and watch the ground redraw itself with the right edge and corner tiles.

  • Movement: animated four-direction farmer sprite, normalized diagonal speed and delta-time updates.
  • Terrain: 32px tiles, grass/earth/stone atlases, and a flood-fill neighbour pass that picks matching edges and corners after every dig.
  • Depth and collision: tree split into behind/front layers, border clamping and a collision rectangle around the trunk.
  • Atmosphere: an 80-second day/night alpha overlay computed from a sine curve.

TypeWriter —
the feel of paper.

Typewriter simulator · keybell, carriage and margin sounds

A small desktop typewriter that treats text entry as a physical machine: a carriage that moves, a line that advances, and a page you can save as an image.

  • Machine feel: per-key typing, carriage left/right, line advance, tab-to-margin and a constrained page area.
  • Sound design: key, return and margin-bell effects, with mute control.
  • Output: clear, mute and export the finished page to a PNG under resources/saved_pages/.
  • Shipped source: CMake project, C++17, SFML 2.5+ and a README with build steps.

Wind by Repora Software Engineer, Red Software · 2026 · wind.repora.com ↗

The terminal that follows you —
built for AI agents.

What it is A terminal app for developers who work with AI coding agents. Terminals normally die with the window: close the laptop lid or lose Wi‑Fi and the build, the server and the agent session go with it. Wind keeps every terminal running on the host machine, then lets the same session be opened from a desktop window or a phone. The Chat view reads the agent's output and turns its questions — “may I run this command?” — into buttons you can answer from anywhere.

My area Native clients — iOS & macOS
iOS · SwiftUI + UIKit

Library/Live/History views, device and terminal switcher, QR pairing and camera scan, approval prompts, Chat view, terminal surface and input, reconnect handling, SSH + Keychain, in-app purchases. In development — not yet on the App Store.

macOS · desktop app

Native OS probes for busy status, foreground program and interrupt; Dock-click activation; relay preference without a daemon restart; stop-confirmation; Devices page with website preview.

Backed by the shared Go monorepo — relay, daemon and port forwarding work lives there too.

  • Port forwarding, end to end: wind forward over the authenticated device stream — owner allowlist with default deny, warm stream pool, limits, timeouts and a revocation test.
  • Website preview over the relay: desktop Devices page, iOS and Android — verified on a physical iPhone over cellular and in Chrome.
  • Cross-platform delivery: 14 PRs to a ~340K-line Go monorepo, working directly with the senior team.

How a feature ships

Agents for breadth. Tests for truth.

The workflow I used on Coinfall, and the one I use daily on Wind.

01
Pure core first

Game math as deterministic C# with no engine references. Seeded logic, unit tests, a simulated economy.

02
Agents for the edges

Claude Code and Codex for scaffolding, refactors and test ideas. Every change reviewed against the real code.

03
Drive the real build

The game runs an automated UI walkthrough: it clicks real buttons, screenshots each state and audits layout.

04
Verify the artifact

Device build, real screenshots, RTP simulation. A green test is not a feature — the build is the claim.
